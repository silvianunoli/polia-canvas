1. Product overview

Pólia One (one.usepolia.com.br) is a back-office web app for small Brazilian brands that sell physical products. It keeps products, stock, sales, finances, pricing and goals in one place. Most of our sellers sell on several channels at once (Instagram, WhatsApp, fairs, their own site and marketplaces) and lose track of stock and real profit because each channel lives in a different spreadsheet.

The TikTok Shop integration connects a seller's shop to her Pólia One account so that:

  1. every paid TikTok Shop order becomes a sale in Pólia One automatically, with items, price, date and an estimated channel fee;
  2. stock stays the same in both places: a sale on any channel lowers the Pólia One stock, and Pólia One sends the new quantity to the TikTok listing;
  3. the seller sees what each TikTok sale actually earned after fees and product cost, next to her other channels.

The integration is available on the Pólia One Pro plan. It is live in production and has been tested end to end with the Partner Center development shop.

3. Data flow

Authorization Pólia One → TikTok authorization page (with a random state) → redirect to one.usepolia.com.br/configuracoes/integracoes/tiktok with code → server exchanges the code for tokens → tokens stored encrypted in the Supabase Vault. When the authorization starts on TikTok's side (no state), the seller must confirm the shop name in Pólia One before it is linked.

Orders TikTok webhook (order status change) → tiktok-webhook function verifies the signature and queues the order ID, answering in under 3 seconds → scheduled job every minute → tiktok-sync fetches the order detail and records or cancels the sale. A sweep every 15 minutes searches orders updated since the last sync, so a missed webhook is recovered.

Stock stock movement in Pólia One → database trigger queues the linked SKUs → tiktok-sync reads the product's warehouse and sends the absolute available quantity with Update Inventory. Sending the absolute value makes retries safe.

Tokens the access token is renewed with the refresh token before it expires. If TikTok refuses the renewal, the connection is marked as error and the seller is asked to reconnect.

5. Business rules

  • When an order becomes a sale: statuses ON_HOLD, AWAITING_SHIPMENT, PARTIALLY_SHIPPING, AWAITING_COLLECTION, IN_TRANSIT, DELIVERED and COMPLETED create the sale as receivable. UNPAID orders are ignored until paid.
  • Cancelled (CANCELLED) after the sale exists: the sale is cancelled and linked stock is returned.
  • Idempotency: one sale per order ID per account, enforced by a unique index. Webhook repeats and sweeps never duplicate a sale.
  • Item price: original price minus seller discount, grouped by SKU and price.
  • Unlinked item: the sale is still recorded, without changing stock, and the order note lists the unlinked products.
  • Fee: estimated from the TikTok Shop fee rule the seller registers in Pólia One (percentage plus fixed amount).
  • Stock to TikTok: only linked SKUs, only while the seller keeps the option on; negative stock is sent as zero; up to 5 attempts per change, with the error kept for review.

7. Security

  • Tokens never reach the browser; all TikTok calls run on the server (Cloudflare Workers and Supabase Edge Functions). App key and secret live in environment secrets, never in source code.
  • Every API request is signed with HMAC-SHA256 as specified. Webhooks are accepted only with a valid signature (HMAC of app key plus raw body), compared in constant time.
  • OAuth state is a random UUID stored per account and cleared after use. A shop already linked to another Pólia One account cannot be linked again (unique index).
  • Database tables of the integration have row-level security on and no access for browser roles; sales are written by server-only functions that check the account owner of every product variation.
  • A lock prevents two sync runs at the same time. Errors are logged without tokens or buyer data.
  • The company's Information Security and Data Protection Policy (submitted with the security questionnaire) covers access control, MFA on administrative accounts, incident response and data subject requests under Brazil's LGPD.

8. Screens

  • Settings > Integrations, TikTok Shop card: what Pólia One imports and what it does not do; Connect button (Pro only). When connected: shop name, last sync, number of linked listings, "Ligar anúncios", the stock option and Disconnect.
  • Authorization return: confirms the connection, or asks "Connect this shop?" with the shop name when the authorization started on TikTok.
  • Ligar anúncios: one row per TikTok SKU with the suggested Pólia One variation and the reason (SKU, name, none); options per row: link to a variation, link to a product without stock control, create a new product, or do not link.
  • Sales: TikTok orders appear with the "TikTok Shop" channel label, like any other channel.

9. How to test

  1. Log in at https://one.usepolia.com.br with the test account provided in the review form (Pro plan).
  2. Settings > Integrations > TikTok Shop > Conectar. Authorize your test shop.
  3. Click "Ligar anúncios", review the suggestions and save.
  4. Place a test order in the shop. Within about one minute it appears in Vendas as "a receber" and the linked stock goes down.
  5. Turn on "A Pólia cuida do estoque" and change a quantity in Produtos: the TikTok listing updates within about one minute.
  6. Cancel the test order: the sale becomes "cancelada" and the stock returns.

10. Out of scope in this version

  • Creating or editing listings and prices on TikTok Shop.
  • Buyer messaging and customer service.
  • Fulfillment, shipping labels and returns handling.
  • Reconciliation with real settlement amounts (planned, using Finance Information).
