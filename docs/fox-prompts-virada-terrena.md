# Pólia Fox — 7 Prompts Prontos (Virada Terrena)

**Mantra de uso:** mesma raposa, só pose + expressão + adereço mudam.
O estilo, a linha, a paleta e a anatomia são fixos. Nunca altere o bloco de base — só substitua a seção de pose.

**Referência de estilo:** ver `polia_fox_mascot.md` em memory para lições das iterações anteriores e critérios de aceitação visual.

**Ordem de geração recomendada:**
1. Gerar estados 1-4 primeiro (Acolhedora, Celebrante, Pensativa, Animadora)
2. Validar consistência entre os 4 — mesma espessura de linha, mesma proporção
3. Se aprovados, gerar estados 5-7 (Orgulhosa, Idle, Erro)
4. Nunca gerar todos de uma vez — cada lote precisa de validação antes do próximo

## Pós-processamento obrigatório (todos os estados)

O Flux.2 Flex gera com fundo creme mesmo com instrução de transparente — isso e esperado. Fluxo apos gerar:

1. Importe o PNG no Figma na pagina "Fox"
2. Selecione a imagem → plugin "Remove BG" ou "Remove Background"
3. Verifique se o INTERIOR DO CORPO tambem ficou transparente (nao so o entorno)
4. Se o corpo veio com fill bege/branco: edite manualmente ou re-execute com config "transparent inside"
5. Exporte como PNG com alpha channel — nome `fox-[slug].png`
6. Opcional: exporte SVG para uso com `currentColor` no dark mode

Custo estimado total: ~3.360 creditos (7 estados x 2 variacoes x ~240 creditos)
